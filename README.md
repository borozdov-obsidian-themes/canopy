# Borozdov Canopy

A theme from the Borozdov collection. Two faces — dark **Grove**, a living emerald
sanctuary, and light **Glade**, the same forest in a clearing at noon. Deep forest-green
surfaces, a luminous display serif and one mint glow for what you act on.

![Borozdov Canopy in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/canopy/main/screenshots/dark.png)

![Borozdov Canopy in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/canopy/main/screenshots/light.png)

## Principles

- **A forest vault.** Every surface is green — depths for the page, tide for cards, lagoon
  for the featured one — never grey and never black.
- **One mint glow.** A single luminous mint is the only saturated colour: links, the caret,
  a checked task, a toggle, tags and the main button. The only shadow on the page is its
  glow, around the main button and the plain note.
- **An editorial serif.** Forum, a display serif, for the title, the two largest headings
  and pull quotes, set large with tight leading; the platform's own sans for everything
  else.
- **Soft shapes.** Buttons and tags are pills, checkboxes are round, cards keep 12px
  corners.

## Features

- Dark and light modes, following Settings → Appearance → Base color scheme
- Callouts as lagoon cards with the title in the type's colour; the plain note glows
- Tags and property values as ghost pills drawn in mint
- Pull quotes in the display serif, two sizes up, behind a mint rule
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Canopy**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/canopy/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Canopy/`, then choose Borozdov Canopy under
Settings → Appearance → Themes.

## Font
